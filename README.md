# Insta-Check

Website sederhana untuk memeriksa hubungan Followers dan Following Instagram menggunakan file ekspor data resmi Instagram (ZIP).

## Fitur

- **Followers**: Menampilkan daftar akun yang mengikuti Anda
- **Following**: Menampilkan daftar akun yang Anda ikuti
- **Belum di-follow balik**: Akun yang mengikuti Anda tetapi tidak Anda ikuti kembali
- **Tidak follow back**: Akun yang Anda ikuti tetapi tidak mengikuti Anda kembali

## Keamanan dan Privasi

- Seluruh proses dilakukan di browser Anda (100% client-side)
- Tidak ada data yang dikirim ke server
- Tidak ada penyimpanan permanen
- Tidak memerlukan login Instagram
- File ZIP diproses secara lokal

## Cara Menggunakan

<ol>
       <li>
        Buka Instagram → Profile → Settings → Accounts Center atau Akun
        Meta
       </li>
       <li>
        Pilih "Your information and permissions" (Informasi dan izin
        anda) → "Export your information (Ekspor informasi anda)
       </li>
       <li>Klik "Create export" (Buat Ekspor)</li>
       <li>Pilih Akun yang mau di cek</li>
       <li>Pilih "Export to Device" (Ekspor ke perangkat)</li>
       <li>klik Sesuaikan informasi</li>
       <li>
        Hapus semuanya kecuali "Followers and following" (Pengikut dan
        Mengikuti) lalu simpan
       </li>
       <li>Pilih Rentang tanggal "All Time" (Sepanjang waktu)</li>
       <li>Pilih format "JSON"</li>
       <li>Klik "Start Export" (Mulai Ekspor)</li>
       <li>
        Tunggu beberapa saat nanti ada email masuk bisa lakukan cara 1
        dan 2
       </li>
       <li>Scroll kebawah akan ada Unduhan yang tersedia</li>
       <li>Klik Unduh</li>
       <li>Unggah file ZIP tersebut di sini</li>
      </ol>
